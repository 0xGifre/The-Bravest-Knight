# Запуск гри на Mac

Відкрийте термінал у цій папці та виконайте:

```bash
/opt/homebrew/bin/python3.12 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python main.py
```

Якщо Python 3.12 не встановлено: `brew install python@3.12`.
В IDE виберіть інтерпретатор `.venv/bin/python` цієї папки.

Керування: WASD або стрілки — рух; пробіл — постріл; R — перезаряджання; Esc — пауза.

## Виправлення

- Windows-шрифти замінено стандартним шрифтом Pygame.
- Виправлено шлях до зображення героя та запуск з іншої робочої папки.
- Додано заміни відсутніх wizard.py та secondWizard.py. Вони використовують наявний спрайт NPC; розташування підібрано відповідно до зон діалогів і перешкод.
- Відсутні сюжетні картинки замінено текстовими підказками. Це новий текст, а не відновлений оригінальний сюжет. Якщо додати оригінальні images/Plots/firstPlotPhoto.png і secondPlotPhoto.png, гра використає їх.
- Усунуто накопичення перешкод у першій кімнаті, обмежено FPS у меню, виправлено перевірку нижнього краю для пострілів та координату кнопки повернення з налаштувань.
- Перемикач звуків тепер керує звуками пострілу й перезаряджання; на паузі скидається утримуваний рух.

Це виправлення запуску наданого неповного проєкту. Бос, умова перемоги та повний оригінальний сюжет у наданому коді не реалізовані; їх не додано.
